CURRENT PROJECT

HerculesScanner

An upgraded web security assessment platform focused on authorized vulnerability scanning, reporting and remediation guidance.

Project Overview

HerculesScanner is an upgraded version of my original web scanner.

The platform is designed around authorized security testing. Before a scan can be performed, the system is intended to verify that the user has permission to assess the target website.

Once authorization has been established, users can configure security scans and receive structured reports describing potential vulnerabilities and recommended remediation.

The long-term goal is to turn HerculesScanner into a more complete cybersecurity SaaS platform rather than simply a command-line scanner.

Technologies

Python FastAPI React SQL Cybersecurity REST API

Key Features

Authorization

Designed to ensure users have permission to perform security assessments on a target.

Scheduled Scanning

Users can configure how frequently security assessments should be performed.

Vulnerability Reports

Generates structured reports describing potential security weaknesses.

Risk Explanation

Explains why identified weaknesses matter and what risks they may introduce.

Remediation Guidance

Provides guidance for addressing discovered security issues.

Web Dashboard

Designed around a web interface for managing scans and viewing security results.
