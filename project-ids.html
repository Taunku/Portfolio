Real-Time Intrusion Detection System

A Python-based security monitoring system designed to detect suspicious activity, calculate risk and simulate automated response.

Project Overview

This project is a real-time intrusion detection system built in Python to monitor security logs and identify potentially suspicious behaviour.

Instead of relying only on individual events, the system analyses activity over a sliding time window to identify patterns that may indicate malicious behaviour.

Detected activity is assigned a risk score, allowing the system to distinguish between lower-risk events and potentially serious security activity.

The project also includes simulated IP blocking and security alert logging, demonstrating how detection can be connected to an automated response workflow.

Key Features

Risk Scoring

Technical Approach

The system processes security log events and evaluates activity within a sliding time window. This allows the detection logic to identify repeated or unusual behaviour instead of treating every event independently.

When activity crosses defined thresholds, the system calculates a risk score and generates a security alert.

The response layer can then simulate blocking the associated IP address, demonstrating the relationship between detection and automated defensive action.
